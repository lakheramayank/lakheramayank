An automated platform for benchmarking machine learning models on uploaded datasets.

- Benchmarks **30+ regression and classification models**
- Compares metrics such as accuracy, F1-score, R², RMSE, and execution time
- Automates preprocessing, including missing-value handling and categorical encoding

### 🎓 ADGIPS AI Assistant

A retrieval-augmented generation (RAG) chatbot for answering institutional queries using official documentation.

- React.js frontend with a Python backend
- Uses **LangChain and Pinecone** to retrieve relevant document context
- Uses **Gemini 1.5 Flash** to generate context-aware responses

**Stack:** Python · LangChain · Pinecone · React.js · Gemini
